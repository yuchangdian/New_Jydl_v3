# DevEco Studio 之外查看项目日志

## 项目当前的日志方式

项目 ArkTS 主要使用 `hilog.info/warn/error`，C++ 通过 `OH_LOG_Print` 写系统 HiLog。可以通过 SDK 自带的 `hdc.exe` 在 PowerShell、Windows Terminal 或其他终端查看，无需打开 DevEco Studio。

本机已确认存在：

```text
C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe
```

已读取本机 `hdc -h` 确认支持 `list targets`、`hilog`、`shell` 等命令。本次查询设备列表未返回连接目标，未抓取实际设备日志。

## 方法一：运行已有脚本

根目录已有 `看TCP日志.ps1`：

```powershell
Set-Location 'E:\baidu\arkTS_code\New_Jydl_v3'
.\看TCP日志.ps1
```

先连接设备并启动应用，按 Ctrl+C 结束查看。

脚本按包名 `com.example.new_jydl_v3` 找进程 PID，再筛选 `JY_TCP_ARK`、`JY_TCP_NATIVE`、`JY_TCP_SERVER`、`JY_ENTRY` 四个标签。适合检查 TCP 客户端及服务端启动、接收、发送和解包。应用重启后 PID 可能改变，需要重新运行脚本。该脚本的四个标签不会覆盖所有页面及 NAPI 日志。

## 方法二：PowerShell 实时查看及过滤

```powershell
$hdc = 'C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc list targets
& $hdc hilog | Where-Object { $_ -match 'JY_|RealtimeMonitoring|IPC_Util' }
```

按 Ctrl+C 结束。这里按标签/关键词筛选，没有绑定固定 PID。

| 标签 | 项目中的来源和用途 |
| --- | --- |
| JY_ENTRY | Ability 入口和生命周期 |
| JY_TCP_ARK | ArkTS 加载原生模块、启动 TCP |
| JY_TCP_NATIVE | C++ TCP 连接、收包、发包及解包 |
| JY_TCP_SERVER | 本机 2404 服务监听、客户端连接和断开 |
| JY_TELEMETRY_NAPI | 已有遥测 NAPI 日志点 |
| JY_SETTING_NAPI | 已有定值 NAPI 日志点 |
| RealtimeMonitoring | 实时指标页面的读取/请求异常 |
| IPC_Util | IPC 服务连接及请求 |

只看 TCP：

```powershell
& $hdc hilog | Where-Object { $_ -match 'JY_TCP_NATIVE|JY_TCP_ARK' }
```

多台设备同时连接时，用 `hdc -t 连接标识 hilog` 指定目标，连接标识取自 `list targets`。

## 方法三：一边看一边保存到电脑

```powershell
$hdc = 'C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
$logFile = Join-Path 'E:\baidu\arkTS_code\New_Jydl_v3\md' ('运行日志_' + (Get-Date -Format 'yyyyMMdd_HHmmss') + '.log')
& $hdc hilog |
  Where-Object { $_ -match 'JY_|RealtimeMonitoring|IPC_Util' } |
  Tee-Object -FilePath $logFile
```

终端会持续显示，同时写入本机文件。结束后可用编辑器搜索，或继续在另一终端查看：

```powershell
Get-Content -LiteralPath '完整的日志文件路径' -Tail 100 -Wait
```

需要保存全部系统日志时，可去掉 `Where-Object` 过滤环节。

中文终端编码可沿用现有脚本的设置：

```powershell
[Console]::InputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
```

## 设备控制台及网络连接

若开发板串口控制台或已配置的 SSH 能进入系统 shell，也可以执行 `hilog`，配合设备端 `grep` 筛选。系统需包含该命令且当前账号有读取权限。

本机 `hdc -h` 也支持 `tconn IP:端口`；设备已经开启 HDC 网络调试服务时，可以通过网络连接后执行同样的日志命令。项目 TCP 业务端口与 HDC 调试端口分别配置。

## 当前告警页面的日志覆盖范围

`CommonSetting_PowerQuality_Set.ets` 主要通过 `statusText` 显示读取结果，没有逐项打印 49 个定值；通用 `jybsmr131_napi.cpp` 的读取函数也没有逐字段日志。现有日志工具可以查看已输出的日志，核对每个告警定值需要在读取成功、字段解析和赋值处添加日志点。

本次未修改业务日志代码或现有脚本，仅保存查看方法。
